# External design resources

Companion resources that pair well with Cursor FE Kits rules and token templates. These are **not vendored** in this repo — browse and copy what you need into your project.

## Refero Styles

**[styles.refero.design](https://styles.refero.design/)** — high-quality `DESIGN.md` examples for AI agents.

Browse 2,000+ AI-readable design systems extracted from leading product websites. Each style includes colors, typography, spacing, components, and a ready-to-use `DESIGN.md` you can drop into Cursor, Claude Code, Codex, v0, or Lovable.

### Why use it with Cursor FE Kits

| Cursor FE Kits gives you… | Refero Styles gives you… |
|---------------------------|----------------------------|
| **How** to build UI (rules, UX laws, a11y) | **What** a specific brand looks like (tokens, components) |
| Generic token templates in `design/tokens/` | Real-world examples (Linear, Apple, Calendly, etc.) |
| Stack-agnostic principles | Product-specific visual language |

Use both: **rules for behavior**, **Refero `DESIGN.md` for taste**.

### Workflow

1. Install Cursor FE Kits (lean or full profile).
2. Open [Refero Styles](https://styles.refero.design/) and search for a brand or aesthetic you want.
3. Copy the `DESIGN.md` into your project root or `design/` folder.
4. Fill in or replace `design/tokens/*.md` with values from the Refero style if helpful.
5. Let Cursor apply your rules + the brand-specific design doc together.

### Examples on Refero

Trending styles include product sites like Linear, Apple, Calendly, Dub, and Ui — each with a full `DESIGN.md` breakdown.

### Connect to your AI

Refero supports connecting to Cursor and other AI tools so agents can browse styles directly. See their site for the latest integration options.
